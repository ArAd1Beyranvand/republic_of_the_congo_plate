# republic_of_the_congo_plate

Republic of the Congo's licence plates for the plate_core library — the regular black-on-white plate with the CEMAC emblem, one theme, Latin alphabets and an advisory validator.

## Quick start

### Install (Kotlin)

Copy `kotlin/src/commonMain/kotlin/plates/countries/republic_of_the_congo/` into `plate_core/kotlin/src/commonMain/kotlin/plates/countries/`.

Then run the tests from `plate_core/kotlin/`: `./gradlew jvmTest`.

### Use

```kotlin
import plates.countries.republic_of_the_congo.country

val spec = country.specs["cg.private"]
println(country.pkg)
```

## Specs

The specs are the same in every language (they come from shared data).

- `cg.private`

## Themes

- `RepublicOfTheCongoThemes.private`

## Change it

- Specs: `country.specs`, by id.
- Themes: `country.themes`.
- Validators: `country.validators` (`RepublicOfTheCongoValidator`).
