# republic_of_the_congo_plate

Republic of the Congo's licence plates for the plate_core library — the regular black-on-white plate with the CEMAC emblem, one theme, Latin alphabets and an advisory validator.

## Quick start

### Install (Python)

Copy `python/plates/countries/republic_of_the_congo/` into `plate_core/python/plates/countries/`.

Then run the tests from `plate_core/python/`: `pytest`.

### Use

```python
from plates.countries.republic_of_the_congo.data import SPECS, THEMES

spec = SPECS["cg.private"]
theme = THEMES["RepublicOfTheCongoThemes.private"]
print(spec.id)
```

## Specs

The specs are the same in every language (they come from shared data).

- `cg.private`

## Themes

- `RepublicOfTheCongoThemes.private`

## Change it

- Pick a spec: use another key of `SPECS`.
- Pick a theme: use another key of `THEMES`.
- Validators: `VALIDATORS` maps the names `RepublicOfTheCongoValidator` to classes.
